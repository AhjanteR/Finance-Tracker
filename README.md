# Personal Finance Tracker

A personal finance dashboard designed to track spending, savings, debt repayment, financial goals, and investments.

## Features 

- Expense Trackimg
- Monthly spending summaries
- Savings goals
- Debt payoff tracking
- Recurring bills and subscriptions
- HYSA tracking
- Investment portfolio tracking
- Financial progress visualizations
